# java-racingcar-precourse

## 구현 기능 목록 정리 (비즈니스 로직 기준)

- [ ] 사용자에게 자동차 이름 목록 입력을 받는다.
    - [ ] 잘못된 입력의 경우 예외를 발생시킨다.
- [ ] 사용자에게 이동 시도 횟수를 입력 받는다.
    - [ ] 잘못된 입력의 경우 예외를 발생시킨다.
- [ ] 경주를 시작한다.
    - [ ] 모든 자동차에 대해 n 차수를 진행한다.
        - [ ] 이동을 시도한다.
        - [ ] 상태를 출력한다.
- [ ] 우승자를 판단한다.
- [ ] 우승자를 출력한다.

# java-racingcar-precourse

## 구현 기능 목록 정리

### 입력

- [x] 사용자에게 자동차 이름 목록 입력을 받는다.
- [x] 사용자에게 이동 시도 횟수를 입력 받는다.

### 비즈니스 로직

- [x] 자동차 목록을 만든다.
    - [x] 잘못된 자동차 이름 입력의 경우 예외를 발생시킨다.
- [x] 라운드 세션을 만든다.
    - [x] 잘못된 이동 시도 횟수 입력의 경우 예외를 발생시킨다.
- [x] 경주를 시작하고 경주 라운드별 스냅샷 반환한다.
    - [x] 모든 자동차에 대해 n 차수를 진행한다.
        - [x] 이동을 시도한다.
        - [x] 스냅샷을 만든다.
    - [x] 각 라운드별 스냅샷을 반환한다.
- [x] 우승자 목록을 반환한다.
    - [x] 우승자를 찾는다.

### 출력

- [x] 라운드별 스냅샷을 출력한다.
- [x] 우승자를 출력한다.
